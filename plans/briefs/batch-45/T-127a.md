## What to build
1. A PURE scheduler module, e.g. `src/services/localReminders.ts`:
   `buildReminderPlan(config, { lastCompletedWorkoutAt, now, nextWorkoutName? })` → notification requests.
   (a) Weekly repeat per chosen day at the chosen time (plugin shape
   `schedule: { on: { weekday, hour, minute }, allowWhileIdle: true }`; the plugin's weekday is
   1=Sunday..7=Saturday while our config is 0=Sunday — convert, and test it).
   (b) One-shot inactivity nudge at lastCompleted + missedWorkoutAlertDays, at the reminder time (skip if
   in the past or reminders are off). Reserved numeric id ranges per type (e.g. 7100-7106 weekly, 7200
   nudge) so a resync cancels exactly OUR ids and nothing else.
2. Side-effect layer `syncReminders()`: native → cancel our reserved ids, then schedule the plan;
   web → no-op. Never throws to the caller; failures go to `src/utils/logger` (no silent empty catch,
   no console.log).
3. Resync on every app open and after every saved workout: one init hook/function mounted ONCE (one line
   in `src/App.tsx` is allowed — nothing else there). In a code comment AND in your report, state the
   honest limitation: the device only knows what it was told the last time the app was open — that is why
   resync-on-open is required.
4. Settings UI (`NotificationsSection.tsx`): when 'תזכורת אימון' is ON, reveal 7 day chips
   (א ב ג ד ה ו ש, Sunday first, RTL) and a native `<input type="time">`. Reuse SettingsRow/SettingsCard/
   SettingsToggle and the SELECTION token pair for chips (a chip is a selection, not a call to action —
   copy how existing filter chips/tabs style their selected state; no new colours). 44px targets,
   Hebrew aria-labels, keyboard operable.
5. Permission ONLY at the moment the user turns reminders ON (never on cold launch). Native: plugin
   `requestPermissions()`; if denied → revert the toggle to OFF and show one short Hebrew line on how to
   enable it in system settings. Web/PWA: honest meta text that reminders fire in the Android app (the PWA
   cannot schedule without a server); the choice still saves.
6. Copy: Hebrew, short, factual, no emoji, no cheerleading (title 'זמן אימון'; body names the next workout
