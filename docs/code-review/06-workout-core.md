## CORE

### `core/WorkoutProvider.tsx`
- **[High] Bug — זמן סגירה נספר כזמן אימון פעיל בשחזור.** ב-initializer, state משוחזר עם `isPaused: true, lastPauseTimestamp: Date.now()` אבל זמן הקיר שעבר בזמן שהאפליקציה הייתה סגורה לא מתווסף ל-`totalPausedTime`. משך נחשב כ-`Date.now() - startTimestamp - totalPausedTime`, אז פתיחה מחדש אחרי שעות מציגה/שומרת משך מנופח.
  - **תיקון:** בשחזור, לחשב את הפער מאז ה-timestamp האחרון ולהוסיף ל-`totalPausedTime`.
- **[Medium] Bug — wake lock leak / לא נרכש מחדש.** `requestWakeLock()` async; אם cleanup רץ לפני שהוא נפתר, `release()` לא קורה. הנעילה גם משתחררת אוטומטית כשהדף מוסתר ולא נרכשת מחדש.
- **[Medium] Code Quality — מימושי wake-lock כפולים** (כאן + `useWorkoutSettings.keepScreenAwake`).
- **[Medium] Bug — דגלי overlay/celebration משוחזרים מאחסון.** אם האפליקציה נסגרה עם overlay פתוח, הוא נפתח מחדש; `showConfetti: true` ישן יכול לשחק confetti שוב.
  - **תיקון:** לפשוט דגלי UI/celebration זמניים בטעינה.
- **[Low] Code Quality** — גישת logger לא עקבית (`logger.workout?.warn?.` מול `logger.workout.error`).

### `core/workoutReducer.ts`
- **[Medium] Bug — `UNDO_LAST_SET` משאיר סט יתום כשauto-increment פעיל.** `COMPLETE_SET` דוחף `nextSet` עם משקל > 0. `UNDO_LAST_SET` מסיר את הסט שנוסף אוטומטית רק כש-`weight===0 && reps===0`.
  - **תיקון:** לעקוב אחרי סטים שנוספו אוטומטית בדגל מפורש (`autoGenerated`).
- **[Medium] Bug — `ADD_REST_TIME` משחית טיימר מושהה (frozen).** כשמושהה, `endTime` מקודד כערך שלילי של ms-נותרים; `ADD_REST_TIME` הופך אותו לזמן מוחלט שגוי.
  - **תיקון:** אם `endTime <= 0` (frozen), להתאים את גודל ה-remaining המאוחסן.
- **[Low] Code Quality** — בלוקי "AUTO ADVANCE EXERCISE" מתים (~15 שורות הערות); `autoAdvanceExercise` לא נקרא.
- **[Low] Code Quality** — ניתוב action כפול (Set + switch).
- **[Low] Bug** — `CREATE_SUPERSET` משתמש ב-`superset-${Date.now()}` בלבד (התנגשות תוך ms).
- **[Low] Code Quality** — `isNaN` גלובלי; להעדיף `Number.isNaN`.

## HOOKS

### `hooks/useWorkoutTimer.ts`
- **[Medium] Bug — זמן pause נספר פעמיים בטיימר המוצג.** עוקב אחרי `extraPausedRef` מקומי וגם מקבל `totalPausedTime` (שה-reducer מגדיל ב-resume). שניהם כוללים את אותו interval, אז הטיימר קופץ אחורה. (השמירה ב-`useWorkoutSave` משתמשת רק ב-`totalPausedTime`, אז הפרסיסטנס נכון — זה תצוגה בלבד.)
  - **תיקון:** להסיר את `extraPausedRef` ולהסתמך על `totalPausedTime`.
- **[Medium] Bug/UX — audio של סוף מנוחה מתעלם מהגדרות המשתמש.** `useRestTimer` קורא `playHeartbeat()`, `navigator.vibrate(...)`, `playDing()`, `triggerHaptic('heavy')`, `speak(...)` ישירות, עוקף `soundEnabled`/`restTimerSound`/`hapticsEnabled`/`voiceCountdownEnabled`.
- **[Medium] Bug/i18n — הכרזה באנגלית קשיחה** באפליקציה עברית RTL: `speak("Rest time complete. Let's crush it.")`. ה-`setTimeout` גם לא מנוקה.
- **[Low] UX** — progress מתאפס בעת הוספת זמן מנוחה.
- **[Low] Code Quality** — `useRestTimer` שני מתנגש בשם עם selector ה-context.

### `hooks/useVoiceCountdown.ts`
- **[High] Bug — voice countdown עובד רק לטיימר המנוחה הראשון.** `announcedSecondsRef` (`Set`) צובר שניות שהוכרזו אבל מתאפס רק ב-unmount. אחרי הטיימר הראשון, הערכים נשארים בסט לנצח.
  - **תיקון:** לאפס את `announcedSecondsRef` כשטיימר חדש מתחיל.
- **[Medium] Bug — speech לא מבוטל ב-unmount.** חסר `synth.cancel()` ב-cleanup.
- **[Medium] Bug — `AudioContext` שנוצר ב-mount יכול להיות suspended** (מדיניות autoplay).

### `hooks/useWorkoutSave.ts`
- **[Medium] Bug — "save failed" כוזב יכול לגרום לשמירות כפולות.** אחרי `saveWorkoutSession`, קורא מחדש דרך `getWorkoutSessions(1)` "לאימות"; כשל קריאה זמני מציב `wasSaved=false` ומציג שגיאה למרות שהכתיבה הצליחה. המשתמש מנסה שוב → session כפול.
  - **תיקון:** להתייחס לכתיבה מוצלחת כהצלחה; אימות best-effort.
- **[Low] Bug** — setState אחרי unmount (אין guard).

### `hooks/usePreviousData.ts`
- **[Medium] Bug — מוטציה של מערך משותף.** `sortSessionsByRecent` עושה `sessions.sort(...)` (in place) על המערך מ-`getWorkoutSessions()`.

## נושאים חוצי-קבצים
- feedback של audio/voice/haptic לטיימר המנוחה מפוצל בין `useWorkoutTimer.useRestTimer` (קשיח, עיוור-להגדרות, אנגלית) ל-`useWorkoutSettings` (מודע-הגדרות). לאחד.
- wake lock נרכש ב-3 מקומות עם אותו race; להחזיק במקום אחד.
- כמה `useEffect` data loads ללא cancellation guards.
- a11y של form/toggle (`role="switch"`, `aria-pressed`, `aria-current`, `role="alert"`).

**לתקן ראשונים:** (1) באג append של numpad preset/stepper [High], (2) voice countdown שיורה רק במנוחה הראשונה [High], (3) זמן סגירה שמנפח משך אימון משוחזר [High], ואז double-count של pause, save-verification כוזב, ו-wake-lock leaks.
